---
name: Editorial review content
description: Rules for generating useful movie and series review copy without unsupported claims.
---

Build editorial sections deterministically from verified TMDB catalog fields. Treat TMDB overview text as the story synopsis, label ratings and financials as recorded or reported facts, use media-accurate movie/series wording, and omit sections whose inputs are unavailable.

**Why:** Imported posts need useful visitor-facing depth, but fabricated plot details, opinions, availability claims, or keyword-stuffed filler would reduce trust and create SEO risk.

**How to apply:** Reuse the shared review composer for public metadata. Keep screenshots, trailers, credits, themes, and related navigation as separate factual sections, with the original unmatched-post fallback preserved.
